🚀 I built an Iron Man-inspired J.A.R.V.I.S. that runs 100% offline on consumer hardware with zero cloud dependencies.

Most "AI assistants" today are just API wrappers sending your private voice recordings to cloud servers. If your internet drops or rate limits hit, they stop working.

I wanted something fundamentally different:
An autonomous, secure, edge-native personal AI desktop assistant built on Stanford's OpenJarvis architecture.

Here is what makes this special:

🎙️ Speaker Biometrics: Voice embedding cosine verification rejects unauthorized voices and background chatter with zero cloud calls.
⚡ 100% Offline Pipeline: Vosk (wake word) + faster-whisper (STT) + Ollama Qwen2.5 (local LLM brain) + pyttsx3 (speech output).
🧠 Dual-Engine Fault-Tolerance: Dynamic LLM function calling backed by a sub-20ms deterministic heuristic reflex engine that guarantees core operations never hang.
🖥️ Universal Desktop Automation: Full Windows window management, GPU/CPU telemetry, verified application launching, and atomic memory persistence.
🔁 Closed-Loop Self-Learning: Logs interaction traces and runs autonomous 4-bit QLoRA fine-tuning directly on local GPU, hot-deploying new weights back into Ollama without downtime!
🛡️ Production Rigor: Comprehensive automated test suite with 100% pass rate.

2/5 🎙️ The Audio Pipeline:
• Wake word: Vosk low-power continuous listening ("Jarvis")
• Biometrics: Speaker voice embedding verification (cosine distance < 0.70 rejects intruders)
• Speech-to-Text: faster-whisper int8 running strictly on local device

3/5 🧠 The Dual-Engine Brain:
• Primary: Ollama (Qwen2.5-3B) with native JSON tool calling
• Reflex Engine: Sub-20ms deterministic heuristic fallback for instant telemetry, media, and window management if the LLM is busy or unavailable.

4/5 🔁 Closed-Loop Self-Learning:
Every command is logged as an OpenJarvis trace. 
The system automatically compiles SFT training pairs, triggers 4-bit QLoRA fine-tuning on local GPU, and hot-deploys new model weights back into Ollama without restarts.
