# Brag Skill: Project Showcase & Technical Storytelling

This skill enables the AI assistant to synthesize complex engineering accomplishments into high-converting, authority-building showcase materials for LinkedIn, X (Twitter), GitHub, and engineering portfolios.

## Triggers
- `/brag` or `\brag`
- Requests for video demo scripts, LinkedIn project announcements, portfolio writeups, or engineering highlight reels.

## Principles of an Engineering Brag
1. **Show, Don't Tell**: Ground claims in concrete metrics (e.g., latency, offline resilience, benchmark scores, test pass rate).
2. **Architecture First**: Highlight the system primitives (e.g., OpenJarvis compliance, speaker biometrics, QLoRA fine-tuning).
3. **Contrast with the Status Quo**: Emphasize how this differs from shallow API wrappers (e.g., 100% offline edge processing vs. cloud latency/privacy leaks).
4. **Actionable Call-to-Action**: Provide clear links to code, stars, and open-source contributions.

## Artifacts Produced
- **Video Scripts & Storyboards**: Timed second-by-second cues (hook, architecture, live demo, game-changer feature, CTA).
- **Social Media Captions**: Structured LinkedIn & X posts with hook, feature bullets, GitHub link, and hashtags.
- **Brag Document Entries**: Bullet points for resumes, performance reviews, or portfolio case studies.
